# **App Name**: Nitai Baboolal Portfolio

## Core Features:

- Profile Summary: Display a summary of Nitai's skills and experience, pulled from the provided resume.
- Project Portfolio: Showcase Nitai's projects with descriptions, links, and potentially images or videos.
- Detailed Resume: List Nitai's certifications, education, and work history, with dates and descriptions.
- Contact Information: Provide direct links to Nitai's LinkedIn profile, email address, and other relevant contact information.
- AI-Powered Bio: Generate a personalized summary introduction using Nitai's provided information to be displayed at the top of the page.
- Resume Download: Enable downloading a PDF version of Nitai's resume directly from the site.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082) to evoke trust, intellect, and innovation.
- Background color: Very light gray (#F0F0F0), nearly white, to allow the indigo and accent color to pop, and create a clean, modern appearance.
- Accent color: Soft violet (#D8B4FE), slightly lighter and less saturated than the primary color, used to highlight interactive elements, draw the user's eye, and provide a clean but high-tech aesthetic.
- Headline font: 'Space Grotesk' (sans-serif) for headlines and short amounts of text; this font offers a tech-forward, crisp appearance.
- Body font: 'Inter' (sans-serif) for body; readable and clean.
- Use minimalist, line-based icons in the accent color to represent different sections and skills.
- Employ a clean and modern layout with generous white space to improve readability and focus. Use a single-page design with clear sections and smooth scrolling.
